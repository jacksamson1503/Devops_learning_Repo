CRON JOB: 
  Cron job is used to automate repetitive tasks in linux.it executes commands or scripts 
automatically at a scheduled time.
 
Format ( * * * * *) 
Minutes hour date month day 

Eg: Run backup every Friday at 11.30pm 
Output: 30 23 * * 5 
30 – minutes 
23 – 11PM 
*- every date 
*-Every month 
*- 5 

Sunday-0 
Monday-1 
Tuesday-2 
Wednesday-3 
Thursday -4 
Friday-5 
Saturday – 6
 
Steps create an cronjob (crontab -e)

Environment Variable 
An environment variable is a variable that stores system or user information, such as the 
username, home directory, shell, or command search path. Applications and Linux use these 
variables during execution.
