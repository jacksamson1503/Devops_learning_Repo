Operating system(OS)-An Operating system is an software that manages your computer’s 
hardware and allows applications to run. 
OS Examples – Linux,Windows,Macos 
Linux – Linux is an free open source operating system based on the linux kernel.Maily used for 
servers,cloud platfomrs, docker, android,and Kubernetes. 
Why linux maily used in all companies – Stable,fast,secure,free,Higly customizable,excellent for 
automation. 
Linux Kernel – It is an core of an operating system.it acts as an bridege between the hardware 
and software. 
Ex: 
SHELL – It is an program that accepts your commands and passes them to the kernel. 
TERMINAL – It is an application where you type commands. 
LINUX DISTRIBUTIONS – A linux distributions includes the linux kernel plus software and tools. 
Comman distributes – ubuntu, Debian, red hat enterprise linux, rocky linux, almalinux, fedora.

1./home -There is where normal users keep their personal files. 
Eg: /home/jack 
/home/samson 
/home/ishu 
Each users can work in their own home directory. 

2./root-There is the home dicrectory of the root user(administrator) 
Normal user - /home/jack 
Admin user - /root 

3./etc – It stores system configuration’s file. 
Eg: user accounts ,password settings ,network configurations ,SSH configurations ,Hostname, 
DNS settings.  
/etc/passwd 
/etc/hosts 
/etc/ssh/ 
/etc/fstab 

4./var – it stores files that change frequently. 
Eg: Logs,Mail,Cache,Temp data 
/var -log,cache,mail,spool 
/var/log/syslog 
/var/log/auth.log 

5. /usr -Most installed software is stored here. 
Eg:Applications,Libraries,Documentation,Commands 
When you install packages with apt, many files are placed under /usr. 

6. /bin – This directory contains essential needed by all users. 
Eg: ls,cp,mv,cat,echo,pwd. 

7. /sbin – Contains system admin commands. 
Eg:Reboot,shutdown,fdisk,mkfs,fsck 

8. /tmp – This directory stores the temporary files. 

9. /boot – Contains files required to boot linux. 
Eg: Linux Kernel,Bootloader files (GRUB),initial RAM filesystem. 
If these files are damaged,the system may fail to start 

10. /dev – stands for devices. In linux hardware devices are repredented as files. 
Eg: Hard disks,USB Drivers, Keyboards, Printers 
/dev/sda 
/dev/sdb 
/dev/null 

11. /proc -These is an virtual filesystem.it doesn’t store real files on disk . instaed,it provides 
information about: Running processes, CPU, Memory, Kernel 
Eg: /proc/cpuinfo 
/proc/meminfo 

12. /opt – Used for optional or third-party software. 
Eg: /opt/google 
/opt/custom-app

REDIRECTION AND PIPES: 
echo – is used to display the text on the terminal 
echo “hello” -output hello 
eg: 
echo “deploying an nginx server” 
echo “Bulding an application” 
echo “deployment completed” 
(Overwrite redirection) 
Echo “linux “ > notes.txt – These will rewrite the file.old data will remove 
Echo “linux” >> notes.txt -these will add the new data.old data will wont delete 
| - sends an output of one command as the input to the another command 
Eg: ls | less 

Cat notes.txt | less 
Tee – display an output on the screen and writes it to a file at the same time 
Echo “linux”  | tee notes.txt -these will rewrite the file.old data will remove 
Echo “linux” | tee -a notes.txt - these will add the new data.old data will wont delete 
Eg: df -h  | tee disk_report.txt (you will see the usage and same output saved in the disk_report.txt file)
